2.4 Integración por Fracciones Parciales

Método avanzado para integrar funciones racionales mediante descomposición algebraica

¿Qué es la integración por fracciones parciales?

La integración por fracciones parciales es un método utilizado para integrar funciones racionales.

Una función racional es una fracción formada por polinomios.

\[ \frac{P(x)}{Q(x)} \]

donde:

  • \(P(x)\) es un polinomio
  • \(Q(x)\) es un polinomio

La idea principal consiste en transformar una fracción complicada en varias fracciones más pequeñas y sencillas que puedan integrarse fácilmente.

Idea fundamental del método

Supongamos que queremos integrar:

\[ \int \frac{3x+5}{(x-1)(x+2)}dx \]

Esta expresión puede separarse como:

\[ \frac{3x+5}{(x-1)(x+2)} = \frac{A}{x-1} + \frac{B}{x+2} \]

Después se encuentran las constantes \(A\) y \(B\), y finalmente cada fracción se integra por separado.

¿Cuándo se utiliza?

Este método se usa cuando:

  • La integral contiene una fracción algebraica
  • El denominador puede factorizarse
  • La fracción no puede integrarse directamente
  • Existen productos de factores lineales o cuadráticos

Condición importante

Antes de aplicar fracciones parciales, el grado del numerador debe ser menor que el grado del denominador.

\[ \deg(P(x)) < \deg(Q(x)) \]

Si esto no ocurre, primero se debe realizar división de polinomios.

Tipos de factores del denominador

Tipo de factor Forma de fracción parcial
Factor lineal simple \(\frac{A}{x-a}\)
Factor lineal repetido \(\frac{A}{x-a}+\frac{B}{(x-a)^2}\)
Factor cuadrático irreducible \(\frac{Ax+B}{x^2+1}\)
Cuadrático repetido Varias fracciones con potencias

Primer caso: Factores lineales simples

Este es el caso más sencillo.

\[ \frac{P(x)}{(x-a)(x-b)} \]

Se descompone como:

\[ \frac{A}{x-a}+\frac{B}{x-b} \]

Ejemplo completo paso a paso

Ejemplo 1

\[ \int \frac{5x+1}{(x-2)(x+3)}dx \]

Paso 1 • Descomposición

\[ \frac{5x+1}{(x-2)(x+3)} = \frac{A}{x-2} + \frac{B}{x+3} \]

Paso 2 • Multiplicar por el denominador

\[ 5x+1=A(x+3)+B(x-2) \]

Paso 3 • Expandir

\[ 5x+1=Ax+3A+Bx-2B \]
\[ 5x+1=(A+B)x+(3A-2B) \]

Paso 4 • Comparar coeficientes

\[ A+B=5 \]
\[ 3A-2B=1 \]

Paso 5 • Resolver sistema

\[ A=\frac{11}{5} \]
\[ B=\frac{14}{5} \]

Paso 6 • Reemplazar

\[ \int \left( \frac{11/5}{x-2} + \frac{14/5}{x+3} \right) dx \]

Paso 7 • Integrar

\[ \frac{11}{5}\ln|x-2| + \frac{14}{5}\ln|x+3| +C \]

Segundo caso: Factores lineales repetidos

Si un factor se repite:

\[ (x-a)^2 \]

entonces se necesita una fracción para cada potencia.

\[ \frac{P(x)}{(x-a)^2} = \frac{A}{x-a} + \frac{B}{(x-a)^2} \]

Ejemplo con factor repetido

Ejemplo 2

\[ \int \frac{3x+7}{(x-1)^2}dx \]

Descomposición:

\[ \frac{3x+7}{(x-1)^2} = \frac{A}{x-1} + \frac{B}{(x-1)^2} \]

Después se determinan las constantes y se integran los términos.

Tercer caso: Factores cuadráticos irreducibles

Algunos polinomios no pueden factorizarse en números reales.

Por ejemplo:

\[ x^2+1 \]

En este caso:

\[ \frac{P(x)}{x^2+1} = \frac{Ax+B}{x^2+1} \]

El numerador debe ser lineal porque el denominador es cuadrático.

Ejemplo con cuadrático irreducible

Ejemplo 3

\[ \int \frac{x+3}{x^2+1}dx \]

Se separa:

\[ \int \frac{x}{x^2+1}dx + \int \frac{3}{x^2+1}dx \]

La primera se resuelve con sustitución:

\[ u=x^2+1 \]

La segunda:

\[ \int \frac{1}{x^2+1}dx=\arctan(x) \]

División de polinomios

Si el numerador tiene grado mayor o igual al denominador, primero debe dividirse.

Ejemplo

\[ \frac{x^2+3x+1}{x+1} \]

Se realiza división algebraica antes de usar fracciones parciales.

Cómo reconocer el tipo de descomposición

Denominador Descomposición
\((x-1)(x+2)\) \(\frac{A}{x-1}+\frac{B}{x+2}\)
\((x-1)^2\) \(\frac{A}{x-1}+\frac{B}{(x-1)^2}\)
\(x^2+1\) \(\frac{Ax+B}{x^2+1}\)

Patrones importantes

  • Si el factor es lineal → numerador constante
  • Si el factor es cuadrático → numerador lineal
  • Si el factor se repite → usar todas las potencias
  • Siempre verificar el grado del numerador
  • Factoriza completamente el denominador

Errores más comunes

Error 1

No factorizar completamente el denominador.

Error 2

Olvidar incluir potencias repetidas.

Error 3

Usar numeradores incorrectos.

Error 4

No hacer división de polinomios cuando es necesaria.

¿Por qué este método es tan importante?

Las fracciones parciales son fundamentales porque permiten resolver integrales racionales que aparecen constantemente en:

  • Ingeniería
  • Física
  • Ecuaciones diferenciales
  • Transformadas de Laplace
  • Análisis de circuitos eléctricos
  • Mecánica

Además, este método combina álgebra y cálculo, por lo que desarrolla habilidades matemáticas avanzadas.

Estrategia general para resolver ejercicios

  1. Verificar grados
  2. Factorizar denominador
  3. Elegir forma correcta de fracciones parciales
  4. Multiplicar por el denominador común
  5. Encontrar constantes
  6. Integrar cada término

Conclusión

La integración por fracciones parciales es uno de los métodos más importantes y potentes del cálculo integral.

Aunque inicialmente parece complicado, todo el procedimiento sigue reglas claras y sistemáticas.

La clave para dominar este método es aprender a reconocer patrones y practicar cada tipo de descomposición.

Una vez comprendido, muchas integrales difíciles se vuelven problemas algebraicos organizados y manejables.
