3.2 Cálculo del Área entre un Eje y una Curva

Cálculo de áreas entre curvas mediante integración definida

Introducción

Una de las aplicaciones más importantes de la integral definida es el cálculo de áreas.

El cálculo integral permite determinar el área exacta de regiones limitadas por curvas, rectas y ejes coordenados.

Antes de existir el cálculo integral, encontrar áreas de figuras irregulares era extremadamente complicado.

Gracias a las integrales definidas, ahora es posible calcular áreas con precisión incluso cuando la frontera es una curva compleja.

Idea geométrica del área

El área bajo una curva puede imaginarse como la suma de muchísimos rectángulos muy pequeños.

Cada rectángulo tiene:

  • Una base infinitamente pequeña
  • Una altura dada por la función

Sumando todos los rectángulos aparece la integral definida.

\[ \int_a^b f(x)\,dx \]

Área entre una curva y el eje x

Cuando una función está arriba del eje x en un intervalo \([a,b]\), el área se calcula mediante:

\[ A= \int_a^b f(x)\,dx \]

Donde:

  • \(A\) representa el área
  • \(f(x)\) es la función
  • \(a\) y \(b\) son los límites

Primer ejemplo completo

Ejemplo

\[ y=x^2 \]

Calcular el área bajo la curva entre:

\[ x=0 \quad \text{y} \quad x=2 \]

Paso 1 • Construir la integral

\[ A= \int_0^2 x^2\,dx \]

Paso 2 • Integrar

\[ \int x^2\,dx= \frac{x^3}{3} \]

Paso 3 • Evaluar

\[ \frac{x^3}{3}\Big|_0^2 \]
\[ \frac{2^3}{3}-\frac{0^3}{3} \]
\[ \frac{8}{3} \]

Resultado:

\[ A=\frac{8}{3} \]

¿Qué ocurre si la función está debajo del eje x?

Cuando la función está debajo del eje x, la integral produce un valor negativo.

Sin embargo, el área nunca puede ser negativa.

Por ello se utiliza valor absoluto.

\[ A= \left| \int_a^b f(x)\,dx \right| \]

Ejemplo con área negativa

\[ y=-x \]

En el intervalo:

\[ [0,2] \]

Integral

\[ \int_0^2 -x\,dx \]

Integrar

\[ -\frac{x^2}{2} \]

Evaluar

\[ -\frac{2^2}{2} \]
\[ -2 \]

El área real es:

\[ A=2 \]

Área entre dos curvas

En muchos problemas el área está limitada por dos funciones.

En esos casos:

\[ A= \int_a^b [f(x)-g(x)]dx \]

Donde:

  • \(f(x)\) es la curva superior
  • \(g(x)\) es la curva inferior

Cómo identificar cuál función va arriba

Este es uno de los puntos más importantes.

Siempre debes:

  • Graficar mentalmente o en papel
  • Evaluar puntos
  • Ver cuál función tiene mayor valor

El orden correcto es:

\[ \text{Superior}- \text{Inferior} \]

Ejemplo completo entre curvas

Calcular el área entre:

\[ y=x \]
\[ y=x^2 \]

Paso 1 • Encontrar intersecciones

\[ x=x^2 \]
\[ x^2-x=0 \]
\[ x(x-1)=0 \]
\[ x=0 \quad \text{y} \quad x=1 \]

Paso 2 • Identificar curva superior

En el intervalo \([0,1]\):

\[ x>x^2 \]

Entonces:

\[ A= \int_0^1 (x-x^2)\,dx \]

Paso 3 • Integrar

\[ \frac{x^2}{2}-\frac{x^3}{3} \]

Paso 4 • Evaluar

\[ \left( \frac{1}{2}-\frac{1}{3} \right) - 0 \]
\[ \frac{1}{6} \]

Resultado final:

\[ A=\frac{1}{6} \]

Áreas con varias regiones

Algunas funciones cruzan el eje x o se cruzan varias veces entre sí.

En esos casos es necesario dividir el problema en varias integrales.

Cada región debe calcularse por separado.

Errores más comunes

Error 1

Restar las funciones en orden incorrecto.

Error 2

No encontrar correctamente los puntos de intersección.

Error 3

Olvidar el valor absoluto cuando la función está bajo el eje x.

Error 4

No dividir regiones cuando cambia la posición de las curvas.

Patrones importantes

Situación Integral
Área bajo una curva \(\int_a^b f(x)\,dx\)
Área entre curvas \(\int_a^b [f(x)-g(x)]dx\)
Área bajo el eje x \(\left|\int_a^b f(x)\,dx\right|\)

Tips importantes

  • Haz siempre un bosquejo de la gráfica
  • Identifica claramente la curva superior
  • Encuentra correctamente intersecciones
  • Usa paréntesis al restar funciones
  • Divide regiones complejas
  • Verifica signos negativos
  • Comprueba si el resultado tiene sentido geométrico

Aplicaciones reales

El cálculo de áreas tiene muchísimas aplicaciones:

  • Ingeniería civil
  • Arquitectura
  • Diseño mecánico
  • Física
  • Economía
  • Electrónica
  • Modelado matemático

Relación con otras aplicaciones

El cálculo de áreas es la base para:

  • Cálculo de volumen
  • Longitud de arco
  • Centro de masa
  • Trabajo mecánico
  • Probabilidad continua

Conclusión

El cálculo de áreas mediante integrales definidas es una de las aplicaciones más importantes del cálculo integral.

Permite encontrar áreas exactas de regiones limitadas por curvas, algo imposible con geometría elemental.

Comprender cómo identificar curvas superiores, puntos de intersección y regiones es esencial para resolver correctamente estos problemas.

Dominar este tema es fundamental para avanzar hacia aplicaciones más complejas como volumen de sólidos, centros de masa y ecuaciones diferenciales.
